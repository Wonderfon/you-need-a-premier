# Seed Packet Sorting Checklist

- [ ] 1. Gather every seed packet in one place.
- [ ] 2. Read each packet's back and note its recommended sowing month.
- [ ] 3. Set out twelve labeled envelopes or dividers, one for each month.
- [ ] 4. File each packet behind the month it should be sown.
- [ ] 5. Store the sorted packets somewhere cool and dry.
